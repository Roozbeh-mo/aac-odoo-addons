# AAC Mail Message Lock

## معرفی

ماژول AAC Mail Message Lock برای اودو ۱۹ طراحی شده است و امکان ویرایش و حذف پیام‌های سیستم را برای کاربران غیر Administrator محدود می‌کند.

این ماژول مدل استاندارد `mail.message` را توسعه می‌دهد و بدون تغییر در کد اصلی اودو، دسترسی به عملیات ویرایش و حذف پیام‌ها را کنترل می‌کند.

## امکانات

- جلوگیری از ویرایش پیام‌ها توسط کاربران غیر Administrator
- جلوگیری از حذف پیام‌ها توسط کاربران غیر Administrator
- عدم نیاز به تغییر در هسته اودو
- سازگار با Odoo Community 19
- استفاده از سیستم استاندارد دسترسی اودو

## نصب

۱. ماژول را در مسیر افزونه‌های سفارشی اودو قرار دهید:
/mnt/extra-addons/custom/

۲. در اودو حالت توسعه‌دهنده را فعال کنید.

۳. لیست برنامه‌ها را به‌روزرسانی کنید.

۴. ماژول زیر را نصب کنید:
AAC Mail Message Lock
