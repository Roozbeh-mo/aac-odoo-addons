# aac-odoo-addons


مجموعه‌ای از ماژول‌ها و افزونه‌های سفارشی اُدو برای استفاده و توسعه در پروژه‌های شرکت AAC.

این مخزن شامل ماژول‌های مختلف با کاربردهای مدیریتی، فنی و سفارشی‌سازی اُدو است.

## ساختار

هر ماژول در پوشه‌ی مستقل خود قرار دارد و مستندات و فایل‌های موردنیاز آن در همان پوشه نگهداری می‌شود.

## نسخه

ماژول‌ها با توجه به نیاز پروژه برای نسخه‌های مختلف اُدو توسعه داده می‌شوند.
