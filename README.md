# aac-odoo-addons


مجموعه‌ای از ماژول‌ها و افزونه‌های سفارشی اودو برای استفاده و توسعه در پروژه‌های شرکت کولرهوایی آبان  .

این مخزن شامل ماژول‌های مختلف با کاربردهای مدیریتی، فنی و سفارشی‌سازی اودو است.

## ساختار

هر ماژول در پوشه‌ی مستقل خود قرار دارد و مستندات و فایل‌های موردنیاز آن در همان پوشه نگهداری می‌شود.

## نسخه

ماژول‌ها با توجه به نیاز پروژه برای نسخه‌های19 اودو توسعه داده می‌شوند.
